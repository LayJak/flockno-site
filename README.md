# FlockNo Public Site

This repository contains only the public FlockNo website and privacy policy. It intentionally does **not** contain the browser-extension source code, backend source, API credentials, or developer email address.

## Publish with GitHub Pages

1. Create a new **public** GitHub repository, e.g. `flockno-site`.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. GitHub will publish the site at a URL similar to `https://YOUR-USERNAME.github.io/flockno-site/`.
7. Use `https://YOUR-USERNAME.github.io/flockno-site/privacy.html` as the Chrome Web Store privacy policy URL.

No custom domain is required.
